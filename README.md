# ESP32 Smart Home Automation

**Name:** Gnaneshwar  
**Roll Number:** 2301CS68

## Project Description
A Wi-Fi-enabled smart home automation system using ESP32 that monitors environmental conditions and automatically controls home appliances.

## Technologies Used
- ESP32
- ESP-IDF
- Embedded C
- Wi-Fi and HTTP
- DHT11, LDR, HC-SR04 Sensors
- Relay Module

## Features
- Temperature and humidity monitoring.
- Automatic fan and light control.
- Motion/presence detection.
- Wi-Fi-based remote appliance control.
- Web-based monitoring dashboard.
- Automatic and Manual operating modes.
